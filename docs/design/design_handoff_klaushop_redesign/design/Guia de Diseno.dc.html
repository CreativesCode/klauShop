02 · FUNDAMENTOS

Color, tipografía y forma

Color — mismo violeta y ámbar, con roles claros

{{ c.name }}{{ c.hex }}{{ c.role }}

Regla: el ámbar #F59E0B nunca es color de texto sobre blanco (contraste 2.1:1). Úsalo como fondo con texto #111827, o usa #B45309 para texto. El violeta es la única acción primaria; el negro #111827 es la acción secundaria fuerte (carrito, filtros activos).

DISPLAY · SOLO TIENDA Instrument Serif

Títulos editoriales (hero, banners, encargos). Le da carácter de boutique de moda. Peso 400, cursiva para el acento en violeta. Nunca en admin ni en textos menores de 32px.

UI · TIENDA + ADMIN (reemplaza Sora) Manrope

Más compacta y legible que Sora en tamaños pequeños, con cifras tabulares para precios y métricas (tabular-nums). Pesos: 500 texto, 600 enlaces, 700 botones, 800 títulos.
